How to use Agent Aquarium

For version 1.0

Agent Aquarium is a screensaver for your Mac that shows what your Claude Code sessions are doing while you're away. Here's how to set it up and get the most out of it.

What you need

A Mac with Apple silicon (M1 or later), macOS 13 or later, and Claude Code.

Install

  1. Download the zip from the latest release and double-click it to unzip.
  2. Drag Agent Aquarium into your Applications folder.
  3. Open it. The app isn't notarized by Apple yet, so the first time macOS says it can't verify it: click Done, open System Settings → Privacy & Security, click Open Anyway next to the message about Agent Aquarium, and open the app again.
  4. Click Connect Claude Code when asked, then restart any Claude Code sessions that are already open.
  5. In System Settings → Screen Saver, pick Agent Aquarium (under Other). To keep your Mac locked while it shows, set Lock Screen → "Require password after screen saver begins" to Immediately.

Settings

Open them from the fish in your menu bar, or by opening the app.

  • Theme: Aquarium, Warm, Retro pixel or Cosmic.
  • Away message: let people know when you'll be back. Save the ones you use often as presets.
  • Calendar: sign in with Google, or add an Apple or Outlook calendar link, to show your current and next meeting. You can hide meeting names and show only the times.
  • Lock screen: show each agent's tasks, show your Claude plan usage, save battery when your Mac isn't plugged in, and keep your Mac awake while agents work.

The menu bar fish

The fish is outlined when nothing is running, filled in while an agent works, and shows "!" when one needs you. Click it to see your sessions, set your away message, switch theme, put the scene on a second display, start the screensaver or preview the lock screen.

Tips

  • Start it any time: set a Hot Corner to Start Screen Saver in System Settings → Desktop & Dock → Hot Corners.
  • Second monitor: click the fish in the menu bar → Always-On Display to keep the scene on it. Press Esc to close.
  • Plan usage updates when you use Claude Code in Terminal, and is available on Pro, Max and Team plans.

Updating

When a new version is out, the menu bar menu and Settings say so, with a Download button. Replace the app in Applications with the new one; your settings stay.

Troubleshooting

  • My sessions don't show up. Restart Claude Code sessions that were open before you connected it. If it still doesn't work, choose Connect Claude Code in the Agent Aquarium menu.
  • The screensaver is black. Agent Aquarium is off while the app is quit. Open it again.
  • Google says the app isn't verified. Google is still reviewing it. Click Advanced → Go to Agent Aquarium, or add a calendar link instead.
  • Something else? Get in touch.

Uninstall

Agent Aquarium menu → Uninstall Agent Aquarium… removes the Claude Code hooks, the background service and the screensaver. Then drag the app to the Trash.

How it works

Claude Code tells Agent Aquarium what each session is doing through hooks. A small server on your Mac, which only accepts connections from your own Mac, turns that into the scene your screensaver shows. Nothing is sent anywhere; see the privacy policy.
